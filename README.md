# CS-408 Advanced Web Development Assignment 1

## Project Overview
This project demonstrates a basic Node.js development environment and Git version control workflow.

## Tools Used
- Visual Studio Code
- Node.js
- npm
- Git and GitHub

## Project Files
- `app.js` — Displays Hello, World!
- `package.json` — Defines project information and the start script.
- `.gitignore` — Excludes node_modules and environment files.

## How to Run
1. Install Node.js.
2. Open the project folder in the terminal.
3. Run `npm start`.

## Expected Output
Hello, World!
